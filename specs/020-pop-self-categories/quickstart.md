# Quickstart: validar as 12 categorias (020)

```bash
npx jest src/data src/theme src/store src/screens/__tests__/HomeScreen.test.tsx
npm run typecheck && npm run lint && npm test
```

Manual:

1. Home: 12 mini cartas, 4 linhas completas de 3; as duas últimas são Cultura Pop (rosa, claquete) e
   Autoconhecimento (azul, espelho).
2. Cada uma abre um baralho "1 / 30".
3. Resumo do Tudo Misturado: "12 categorias"; com um filtro antigo sem Dilemas: "11 de 12 categorias".
4. Leitura das 60 perguntas (revisão de conteúdo): abertas, acolhedoras, sem temas sensíveis.

Modelo: [data-model.md](./data-model.md).
